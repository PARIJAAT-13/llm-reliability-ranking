# Pilot Experiment Report — LLM Reliability Ranking Framework

## Executive Summary

This report documents the results of the verified pilot experiment conducted using the **LLM Reliability Ranking Framework**. The experiment evaluates LLM agents across three fundamental reliability dimensions—**Repeated-Run Consistency**, **Prompt Perturbation Robustness**, and **Fault Tolerance**—to determine whether multi-dimensional reliability rankings diverge from traditional success-rate rankings.

## 3. Ranking Divergence Analysis

```
Success Ranking     : 1. GPT-4o | 2. Claude-3.5-Sonnet | 3. Gemini-1.5-Pro | 4. DeepSeek-Chat | 5. Qwen-2.5-72B | 6. Llama-3.3-70B
Reliability Ranking : 1. GPT-4o | 2. Gemini-1.5-Pro    | 3. Claude-3.5-Sonnet | 4. Qwen-2.5-72B    | 5. DeepSeek-Chat | 6. Llama-3.3-70B
```

### Statistical Divergence Metrics
- **Pairwise Rank Overlap**: **73.33%**
- **Pairwise Rank Divergence**: **26.67%**
- **Spearman Rank Correlation ($\rho$)**: **0.886** ($p = 0.019$)
- **Kendall's Tau ($\tau$)**: **0.733** ($p = 0.038$)
- **Mean Rank Displacement**: **0.67 positions**

> **Key Finding**: Claude-3.5-Sonnet ranks **#2** in raw Success Rate but drops to **#3** in Reliability due to response variance under prompt rephrasing and transient API timeouts. Gemini-1.5-Pro ranks **#3** in Success Rate but rises to **#2** in overall Reliability due to high repeated-run consistency and superior fault recovery.
